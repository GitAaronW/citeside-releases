# Citeside — Downloads

Public program updates for macOS 13 and later. This repository contains release assets only; it has no API keys, meeting data, personal settings, or source repository history.

[Download the current app](https://github.com/GitAaronW/citeside-releases/releases/latest)

After installing the current app, use **Check for updates / 检查更新** in the app. Updates replace program files and keep existing settings and meeting records. No GitHub login is required for public program updates.

## 给朋友

Citeside 是 Mac 上的会议记录。它记下会上说的话，会后整理成纪要和待办。

下载本页的安装包。系统需要 macOS 13 或更新版本。第一次打开时允许麦克风和屏幕录制。之后在应用里点 **检查更新 / Check for updates**。

登录后的第一次使用，包含 15 小时会议额度和 30 次深度研究。


Family preconfigured installers are distributed separately and remain private. They are never uploaded here. The source repository remains private.

Current public releases are Developer ID signed and notarized by Apple. macOS may still ask for microphone and screen-recording permission on first use.
